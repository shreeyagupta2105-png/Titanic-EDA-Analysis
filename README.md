# 🚢 Titanic Dataset - Exploratory Data Analysis (EDA)

## 📖 Project Overview

This project performs a Mini Exploratory Data Analysis (EDA) on the Titanic dataset.

The objective is to analyze passenger survival patterns using data cleaning, feature engineering, groupby analysis, and data visualization techniques.

This project was completed as part of a Data Science Internship Task.

---

## 🎯 Objectives

- Handle missing values using imputation.
- Perform data cleaning.
- Create meaningful features.
- Analyze survival patterns.
- Generate visual insights.
- Draw conclusions from data.

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## 📊 Analysis Performed

### 1. Data Cleaning

- Missing Age values filled using mean.
- Missing Embarked values filled using mode.
- Cabin column removed due to excessive missing values.

### 2. Feature Engineering

Created:

- Age Group
- Family Size

### 3. Survival Analysis

Studied survival rates based on:

- Age Group
- Embarkation Port
- Family Size

### 4. Visualizations

- Age Distribution Histogram
- Correlation Heatmap
- Survival by Family Size
- Survival by Passenger Class
- Survival by Gender

---

## 📈 Key Insights

- Children had higher survival rates.
- Female passengers survived more frequently.
- First-class passengers had better survival chances.
- Small family groups showed higher survival rates.
- Survival varied across embarkation ports.
